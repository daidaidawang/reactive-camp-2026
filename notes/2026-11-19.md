## 完成的事

**AgentSentinel 全链路闭环（Sepolia → Lasna → Sepolia）：**

```
① Agent 越界下单（60 ETH / 授权上限 10 ETH）
   └─ SentinelExecutor 合约算出证据，发 RiskAlert（金额对比由合约判定，Agent 无法自报）
② Reactive 网络投递到 Lasna
③ 链下 AI 判读服务捕获事件 → LLM 输出结构化 verdict（level=3 + 中文理由）
   └─ 提交 AgentSentinel.submitVerdict()
④ Lasna 规则引擎校验裁决（AI 不能突破链上证据）
   └─ requestCallbackV_1_0 发起跨链回调
⑤ Sepolia 回调落点执行三重处置：
   ├─ CapabilityRegistry.revokeCapability() → 授权撤销
   ├─ AccountabilityVault.slash() → 保证金全额罚没
   └─ AgentRegistry.setStatus(Revoked) → 身份吊销
```

## 踩坑记录（今天最大的收获）

1. **回调落点的每一个外部调用都要显式授权目标合约** —— `AgentRegistry.setStatus` 只允许 owner，回调合约调用直接 revert，整笔处置回滚。教训：撤权链路上的三份合约（capability/vault/identity）权限模型必须统一。
2. **Sentinel 的订阅在构造函数锁定源合约地址** —— 重部署执行器后必须重部署 Sentinel，否则事件静默不投递（且 Lasna 侧还在持续计费）。
3. **Sepolia 官方回调代理是 `0xAa14d9Cd...`**，demo 仓库里的 0x082caf... 已废弃（链上无代码）。
4. 回调代理投递失败时**不 revert 自己的交易**，只发失败事件——排错要解码代理事件 data 才能看到目标合约的 revert 原因。
5. Lasna 部署 gas 上涨（~0.37 lREACT），部署前先查余额。
