## 如何复现

环境：Foundry 1.7.1、Solidity 0.8.35、Node.js 22+。在仓库根目录执行：

```powershell
cd agentsentinel
forge test -vv
node --test scripts/ai-verdict.test.js
```

2026-11-25 实测：Foundry 34 passed、0 failed（AgentSentinel 28 项，Bounded Cron 6 项）；Node.js 12 passed、0 failed。Foundry 测试用 SYSTEM 和 Callback Proxy 替身，不是公开网络交易。

## 赛道 3 的 AI 说明

运行时输入是合约事件中确认过的 Agent、商户、请求金额、最大授权额和回执。AI 输出仅为自然语言解释，供人审阅；超额判定由 `amount > maxSpend` 确定性执行，AI 不能放过违规请求或改变处置等级。当前完成本地规则、AI 输入校验和故障回退测试，没有真实模型调用证据。
