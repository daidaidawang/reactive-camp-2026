# 发布准备与缺口审查

审查日期：2026-11-25。范围：当前仓库中的 AgentSentinel、独立 Bounded Cron100 实验、Foundry 部署脚本、配置模板和本地测试。此记录不是合约安全审计。

## 项目分类

- 框架：Foundry；Solidity 0.8.35，EVM Cancun；Node.js 22 的链下解释脚本。
- 合约：非可升级。代码未使用代理升级框架；Callback Proxy 是 Reactive 网络代付回调费用的入口，不是本项目的可升级代理。
- 类型：受限 ETH 付款、保证金和 Reactive 事件回调原型。
- 发布路径：人工运行 Foundry 脚本；仓库未发现自动部署 CI。
- 网络：源链 Sepolia 11155111，Reactive Lasna 5318007，目标链 Sepolia 11155111。

## 发现与处置

### 已修复：目标网络回调代理不能由任意环境地址替换

原部署脚本只把 `CALLBACK_PROXY_ADDR` 交给构造函数，由构造函数检查它有代码；若 `.env` 误填另一个有代码的地址，脚本仍可能部署并把 Callback 费用发往错误服务。现在 `DeployCallback` 除检查 Sepolia chain ID 和地址有代码外，还要求匹配 [Reactive 官方网络表](https://dev.reactive.network/origins-and-destinations)中的 Sepolia Callback Proxy `0xAa14d9Cd0f788Ca23d11805986C1d8bd035D23b4`。Cron Callback 部署也被限定为 Sepolia，并执行相同代理地址与代码检查。

### 当前测试网部署阻断：缺少本地部署账户与密码配置

仓库根目录和 `agentsentinel/` 下都没有 `.env`；当前进程没有 `CAST_ACCOUNT`、`CAST_PASSWORD_FILE`；Foundry keystore 目录和 `cast wallet list` 也未发现可用账户。私钥路径采用加密 Foundry keystore，脚本不接受明文私钥。没有账户无法签署 Sepolia/Lasna 部署交易，也没有部署人地址可核对测试币余额，因此本次不能广播合约。

可以公开检查的网络前置条件已核对：Sepolia RPC 返回 chain ID 11155111；Lasna RPC 返回 5318007；官方 Sepolia Callback Proxy 与 Lasna SYSTEM 地址均返回有代码。`DeployCore` 也已在 Sepolia RPC 上成功完成无广播模拟；模拟使用临时 sender 和 merchant 地址，估算 gas 成功，但输出的四个预测地址仅来自模拟，不能当作部署地址。以上检查不替代部署人的账户余额与交易签名。

### 测试网部署后仍需完成的证据

当前版本没有经确认的 Executor、Sentinel、Callback 部署地址，没有源链订单/违规交易、Reactive `react()` 交易、目标链 Callback 交易，也没有用同一 `receiptId` 关联的端到端记录。最新版本部署前不得用旧 `deploy_sepolia_core.txt` 里的地址替代。部署后还要读取 Registry/Capability/Vault/Executor/Sentinel/Callback 角色配置，确认 Reactive reserves/debt 与 Callback reserves/debt，并实际触发额度内付款和超额处置。

### 上线范围限制

Executor owner、Vault owner、Registry/Capability 管理员和 Reactive Sentinel owner 是部署者 EOA；测试网演示可以保留并说明，生产部署应先评估多签、角色分离、申诉机制、比例处罚和独立审计。保证金全额罚没是原型固定政策，不是保险或损失定价。`block.timestamp` 用于授权时效和重试等待，Foundry lint 对这些时间比较给出提醒；本业务不依赖精确秒级边界，实际到期判断仍由链上区块时间决定。

## 修改与验证

本次给正式 Sentinel 和 Cron 的目标链部署脚本加入官方 Sepolia Callback Proxy 地址断言和代码检查，并将 Cron 目标链断言固定为已配置的 Sepolia。这样在广播之前可阻止错误网络或错误代理配置。

验证记录：`forge fmt --check` 通过；`forge build` 成功；Foundry 34 passed、0 failed、0 skipped（AgentSentinel 28 项、Bounded Cron 6 项）；Node.js 12 passed、0 failed。编译仍提示 `block.timestamp` 比较的常见 lint 提醒。公共 RPC 的只读 chain ID 和系统/代理代码检查通过。未广播交易。

## 发布结论

**测试网：配置阻断，暂不能发布。** 缺少 Foundry keystore 账户、密码文件路径和部署人测试币余额；不要在聊天中粘贴助记词、私钥或 keystore 密码。部署人把自己的加密 Foundry 账户准备到本机并配置 `.env` 后，才能模拟、核对并广播。

**主网：不具备发布条件。** 当前没有独立审计、生产签名治理和完整链上验证；本原型的资产范围及经济政策也尚未适用于真实资金。
