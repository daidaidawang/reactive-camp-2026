# 发布准备与缺口审查

审查与部署日期：2026-11-25。范围是当前 AgentSentinel、独立 Cron100 实验、部署脚本与本地测试；这不是第三方安全审计。

## 观察与修正

Sepolia Callback Proxy 的环境变量原本只要求地址有代码，误填另一个合约也可能通过。当前 `DeployCallback` 和 Cron 回调脚本都要求匹配 [Reactive 官方网络表](https://dev.reactive.network/origins-and-destinations)的 Sepolia 代理 `0xAa14d9Cd0f788Ca23d11805986C1d8bd035D23b4`，并检查链 ID 与代码。

首次两笔 Sepolia 核心部署交易因 gas limit 不足失败，回执 `status=0`、gas 全部耗尽，没有创建合约。提高估算余量后重新模拟与广播，核心、Reactive、Callback、角色连接均成功。Lasna 有一次 500% gas 余量的广播被 RPC 的单笔费用上限拒绝，未产生链上交易；改用 300% 后成功。公用 Sepolia RPC 曾出现 403 和延迟，最终使用可用 RPC 逐笔确认回执。

## 仍然缺少的证明

Blockscout/Etherscan 页面上的独立源码验证状态、第三方审计、生产签名治理、角色分离、真实 LLM 调用、长期运行可靠性还没有完成。演示账户同时担任项目方、Agent 和商户；本次没有在公开链上人为重放事件或制造目标回调失败，重复处理与失败回滚由本地测试覆盖。Cron100 只有本地替身测试，没有实链部署。

这版只保护进入 Executor 的单商户 ETH 订单；不保护任意 EOA、Safe、DEX、ERC-20 或其他链的资金。保证金全额罚没是原型固定规则，没有申诉和比例处罚。Reactive 网络或回调长期不可用时，保证金可能持续锁定；重试需有人发送交易。主网发布仍需独立审计与治理设计。
